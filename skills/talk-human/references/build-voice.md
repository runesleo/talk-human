# 指令：帮我建我自己的声音层

> 用法：把这整段丢给 Claude / GPT。它会带你从你自己的说话样本，生成一份专属于你的「声音层」清单。**你只出样本、只做确认，提炼和生成交给 AI。**

你要帮用户造一份**声音层**——一份让 AI 辅助写作听起来像**他这个人**的清单。你负责提炼和生成，用户只提供样本、只做审核。全程一步一步来，不要一次问完。

## 第一步 · 要样本

先跟用户要**他自己真实说话/写字**的样本，并这样引导他：

> 我需要一些**你自己**平时说话或写字的原话，越随意越真。两个来源：
> - **你用过讯飞 / TTS / 语音输入 / 听写软件吗？** 那你电脑本地大概率已经存了你自己的语音转录——直接翻出来贴给我，这是最像你的原料。
> - **没有的话**：写一两段东西，**用你平常聊天的语气念出来**（手机录一下转文字，或直接对着输入法说），把「你平时怎么讲话」变成文字贴给我。别端着，越口语越好。
> 先给我十几段就能起步，越多越准。

拿到样本前不要往下走。

## 第二步 · 提炼你的 DNA

从样本里找出并**用大白话报告**给用户：

- 他常用的转折词、口头禅、语气词
- 句子节奏：平均长短、爱短句还是长句、爱不爱空行分段
- 他怎么开头、怎么收尾下结论
- 他的态度标记：自嘲、吐槽、冷幽默、认真
- 他爱用的具体锚习惯（数字、亲身经历、点名具体东西）
- 他最容易滑进去的 **AI 腔坏习惯**（对照 `part-a-ai-tells.md`）

报告完，**请用户确认或纠正**：「这几条像不像你？哪条不对？」

## 第三步 · 生成你的声音层

用户确认后，产出一份清单，格式固定：

```
# 我的声音层

## 负向红线（我最容易滑回的 AI 腔 · 命中即改）
1. ...
2. ...

## 正向硬条款（我独有的活人味 · 至少命中 N 项）
1. ...
2. ...
```

- 用**他自己的真实模式**，不要套通用建议。
- 红线 = 从他样本里看到的、他一放松就会犯的 AI 腔。
- 硬条款 = 他区别于所有人的独特标记（他的口癖、节奏、锚习惯）。

## 第四步 · 交付

- 让用户把这份存成 `voice-layer.md`。
- 告诉他：以后每次改稿，把这份连同草稿一起丢进 `deslop-pass.md`，第三轮就会用它审你的声音。
- 提醒：过一阵（或发现它审得不准时）拿新样本回来重跑，声音层会越来越准。
